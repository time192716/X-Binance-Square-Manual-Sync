# X → Binance Square Manual Sync

一个本地浏览器扩展。它不会自动同步推文；只有你在 X 页面点击某条推文旁边的“同步”按钮时，才会把该条内容发布到币安广场。

## 功能

- 仅限本人：只有当前登录 X 账号自己发布的推文下方会出现“同步”按钮。
- 完整正文：长推文会先自动点击“显示更多”并等待全文展开，不会发送截断的半篇内容。
- 标签保留：保留原文换行、`#话题标签` 和 `$币种标签`。
- 图文同步：支持正文以及最多 4 张推文图片。
- 关键词拦截：默认拦截 `okx`、`欧易` 等相关词，可在设置中修改。
- 总开关：可在扩展弹窗中暂停或恢复手动同步。
- 账号绑定：首次成功同步时绑定 X 用户名，防止误同步其他账号。
- 可靠投递：手动选择后如果遇到临时网络错误，会在本地队列中有限重试。

## QQ 浏览器安装

如果装过旧版 `Auto Sync`，请先在应用中心停用或删除旧版，避免两个版本同时运行。

1. 解压发布包，确保打开的文件夹里能直接看到 `manifest.json`。
2. 在 QQ 浏览器地址栏进入扩展管理页面，也可以从菜单进入“应用中心”。
3. 打开“开发者模式”。
4. 点击“加载未打包的扩展程序”。
5. 选择刚才解压、包含 `manifest.json` 的文件夹。
6. 在扩展设置中填写 Binance Square OpenAPI Key 并保存。
7. 刷新已经打开的 `x.com` 页面。

详细图示操作见 [INSTALL.md](INSTALL.md)。

## 使用方法

1. 打开 `https://x.com/`。
2. 找到当前账号自己发布、想要同步的那一条推文。
3. 点击推文操作栏右侧的“同步”。
4. 按钮显示“已同步”即完成；被关键词规则拦截时会显示“已跳过”。

其他账号的推文不会显示按钮。没有点击的本人推文不会被读取或发布；重复点击同一条推文不会重复发布。

## 设置说明

- `启用手动同步按钮`：关闭后，所有同步请求都会停止。
- `不同步的关键词`：每行一个，大小写不敏感；命中任一词就跳过。
- `绑定的 X 用户名`：首次成功同步后自动生成，可在设置页重置。

如果需要同步另一个 X 账号，请先打开扩展设置，重置绑定账号，再手动同步新账号的一条推文。

## 文件结构

- `manual-sync.js`：识别当前 X 账号，只给本人推文加入按钮，并在同步前展开和读取完整正文。
- `service-worker.js`：校验设置、过滤关键词、下载图片、管理队列并调用 Binance Square API。
- `options.html` / `options.js`：API Key、关键词与账号绑定设置。
- `popup.html` / `popup.js`：暂停开关和最近一次同步状态。

扩展不再包含旧版的 `page-hook.js`、`bridge.js` 或自动监听 `CreateTweet` 的逻辑。

## 隐私与安全

- 仅在你点击“同步”时读取该条推文的文字、作者、状态 ID 和图片链接。
- API Key 仅保存在浏览器本地存储中。
- 图片只在发布前临时下载并转成数据，不上传到其他服务。
- 仅连接 X 图片域名和 Binance Square OpenAPI。

详见 [PRIVACY.md](PRIVACY.md) 与 [SECURITY.md](SECURITY.md)。

## 已知限制

X 如果调整页面 DOM 结构，手动按钮可能暂时不显示；通常先刷新页面即可，仍不显示则需要更新扩展。
